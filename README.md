# 기획 위키

메모를 붙여넣고 양식을 고르면, AI가 **이미지가 들어가는 보기 좋은 위키 문서**로 정리해주는 게임 기획 문서 툴.
AI는 API 키 없이 **이미 로그인된 CLI**(Claude Code, Codex)를 그대로 호출한다.

## 설치 (팀원용)

[Releases](../../releases) 페이지에서 내려받는다.

- **윈도우 10/11**: `…-windows-setup.exe` 실행 → 시작 메뉴의 **기획위키**. 설치 없이 쓰려면 `…-windows-portable.zip`을 풀고 `GihoekWiki.exe`.
- **맥 (M1 이상)**: `…-mac.dmg`를 열고 `기획위키`를 `Applications`로 끌어다 놓는다.
- 서명 없는 앱이라 처음 한 번 경고가 뜬다. 윈도우는 **추가 정보 → 실행**, 맥은 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**.
- 문서는 **문서 폴더의 `기획위키`** 폴더(`config.json`, `projects/`)에 저장된다.
- AI 기능은 `claude` 또는 `codex` CLI가 설치·로그인되어 있어야 한다. Python은 필요 없다.

## 자동 업데이트

앱이 켜질 때(그리고 3시간마다) GitHub 릴리즈를 확인한다. 새 버전이 있으면 왼쪽 아래에 **새 버전 · 업데이트** 버튼이 뜨고,
누르면 내려받아 설치한 뒤 앱이 다시 열린다. 문서(`문서/기획위키`)는 그대로 남는다.

- 맥은 `Applications` 폴더에 넣어 둔 앱, 윈도우는 설치형(setup.exe)에서 동작한다. 윈도우 무설치판은 릴리즈 페이지를 열어 준다.

## 팀과 같이 쓰기 (Git)

프로젝트 폴더를 GitHub **비공개 레포**로 올리고, 팀원을 초대해서 같이 고친다. `git`과 [GitHub CLI](https://cli.github.com)(`gh auth login`)가 필요하다.

1. **만들기**: 새 프로젝트를 만들 때 *GitHub 비공개 레포로 올려 팀과 같이 쓰기*를 켜 두면 레포가 자동으로 만들어진다. 이미 있는 프로젝트는 프로젝트 홈에서 **GitHub에 올리기**.
2. **초대**: 프로젝트 홈 → **팀원** → 팀원의 GitHub 아이디 입력.
3. **참여** (팀원): 첫 화면 **팀 프로젝트 받기**에 초대가 뜬다 → **참여하기**. 레포 주소로 직접 가져올 수도 있다.
4. **동기화**: 프로젝트 홈의 **동기화** 버튼 하나로 내 변경 저장 → 팀원 변경 받기 → 올리기를 한 번에 한다.

같은 문서를 둘이 고쳤으면 팀원 버전을 받고, 내 버전은 `문서 이름 (내 버전 날짜)`로 옆에 따로 저장한다. 아무것도 사라지지 않는다.
되돌리기 기록과 휴지통(`.wiki/`)은 올라가지 않는다.

## 새 버전 내보내기 (자동 릴리즈)

`release.command`를 더블클릭하고 버전을 확인하면 끝. GitHub에 `v0.1.1` 같은 태그가 올라가고,
GitHub Actions가 맥 dmg와 윈도우 설치 파일을 빌드·테스트해서 릴리즈 페이지에 올린다 (10분 정도).

- main에 push만 하면 빌드와 테스트만 돈다 (릴리즈는 안 만듦).
- 직접 빌드: `pip install pyinstaller` 후 `python3 scripts/build.py --version 0.1.0` → `dist/release/`
- 동작 확인: `python3 scripts/smoke.py` (소스), `python3 scripts/smoke.py --built` (빌드한 앱)

## 소스로 실행 (개발용)

필요한 것: Python 3, 그리고 `claude` 또는 `codex` CLI 로그인. 이 폴더의 `config.json`과 `projects/`를 쓴다.

### 맥 앱

`기획위키.app`을 더블클릭한다. 자기 창으로 열리고, 앱을 종료(⌘Q)하면 서버도 같이 꺼진다.
독(Dock)에 끌어다 두면 다음부터 한 번에 켤 수 있다.

- 앱은 이 폴더의 `server.py`와 `data/`를 그대로 쓴다. 코드를 고쳐도 앱을 다시 만들 필요는 없다.
- **폴더를 다른 곳으로 옮겼다면** `build_app.command`를 더블클릭해서 앱을 다시 만든다. (Xcode 필요)
- 앱이 안 열리면 `data/server.log`를 확인한다.

### 브라우저로

```bash
python3 server.py --open
```

`start.command`를 더블클릭해도 된다. 주소는 http://127.0.0.1:4173

## 쓰는 법

0. **프로젝트 만들기**: 첫 화면에서 이름과 한두 줄 소개를 적는다. 소개는 AI가 문서를 쓸 때 참고한다.
1. **+ 새 문서** → 양식 선택 → 메모 붙여넣기 → **AI로 작성**
2. 문서 화면에서 점선 칸을 클릭하거나 이미지를 끌어다 놓으면 바로 들어간다. 편집 화면에서는 ⌘V 붙여넣기도 된다.
3. **✦ AI로 다듬기**: "세력 4개로 늘려줘", "문장 더 짧게" 같은 요청으로 고친다. 이미지는 유지되고, **되돌리기**가 가능하다.
4. 본문의 `[[이름]]`은 위키 링크다. 빨간 링크는 아직 없는 문서이고, 누르면 그 제목으로 새 문서를 만든다.
5. 상태(초안 / 검토 중 / 확정)로 문서가 어디까지 정해졌는지 표시한다.
6. **PDF**: 브라우저 인쇄 → PDF로 저장. 제안서 양식은 그대로 제안서로 쓸 수 있다.

## AI CLI 바꾸기

사이드바 아래 **AI** 선택에서 고르거나 `config.json`을 고친다.
명령어 배열을 바꾸면 모델 지정 같은 옵션도 넣을 수 있다. 예: `["claude", "-p", "--model", "opus", "--tools", "", "--output-format", "text"]`
프롬프트는 stdin으로 전달되고, `{out}`이 있으면 그 파일에서 결과를 읽는다.

## 양식 추가

`public/templates.json`에 항목을 추가하면 끝. 필드 타입:

| 타입 | 용도 |
|---|---|
| `text`, `longtext` | 짧은 글 / 여러 문단 |
| `list`, `tags`, `flow` | 목록 / 키워드 칩 / 순서 흐름(화살표) |
| `cards` | 제목 + 설명 카드 (핵심 재미, 기능) |
| `keyvalue` | 인포박스 (`keys`로 항목 지정) |
| `table` | 표 (`columns`로 열 지정) |
| `timeline` | 연표 |
| `relations` | 관련 문서 링크 |
| `image`, `gallery` | 이미지 한 장 / 여러 장 |

`place`: `lead`(위키 첫 요약), `infobox`(위키 오른쪽 박스), `hero`(제안서 상단 배너).
`layout`: `wiki` 또는 `proposal`.

## 저장 구조 (md 파일)

```
projects/
  <프로젝트>/
    project.md              프로젝트 이름과 소개 (AI가 문서 쓸 때 참고)
    세계관/벨모어.md          양식별 폴더, 문서 하나 = md 파일 하나
    캐릭터/에스벤 노옹.md
    문서/1차 회의록.md        직접 쓴 md 파일도 '자유 문서'로 읽힌다
    images/                 이미지 (md에는 ../images/파일.png 상대 경로로 들어간다)
    .wiki/                  되돌리기 기록, 휴지통(삭제한 문서)
```

- 문서는 일반 마크다운이라 Obsidian, VS Code, GitHub에서 그대로 읽힌다.
- md 파일을 직접 고쳐도 된다. `## 섹션 이름`이 양식 항목 이름과 같으면 그 항목으로 읽히고, 양식에 없는 섹션은 그대로 보존된다.
- 맨 위 `---` 부분(frontmatter)에 양식(template), 상태(status), 만든 날짜가 들어 있다.
- 저장 위치는 `config.json`의 `projectsDir`로 바꿀 수 있다. 예: Obsidian 볼트나 공유 드라이브 폴더.
- 앱에서 삭제한 문서는 지워지지 않고 `.wiki/trash/`로 옮겨진다.
- 예전 JSON 저장본은 `data/docs-json-backup/`에 남아 있다.

폴더째 Git에 올리면 팀이 같이 쓰고 변경 이력도 볼 수 있다.
